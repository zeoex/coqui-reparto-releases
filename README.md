# Coqui Reparto — descargas

App Android de **Autoservicio Coqui** para los vehículos de reparto (hoja de ruta y GPS).

**Instalar:** en *Releases*, bajá `CoquiReparto-x.y.z.apk` desde el teléfono, abrilo y, si Android lo pide, permití instalar apps de este origen.

Las pantallas se actualizan solas. Esta descarga sólo hace falta cuando la app avisa que hay una versión nueva.

Este repositorio no tiene código: sólo los instaladores.
